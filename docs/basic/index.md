# C# 基础指南

本栏目是 C# 语言与 .NET 平台的基础教程，按学习路径组织：

- **类型系统**：struct、record、动态类型、参数传递与懒加载（Lazy<T>）
- **面向对象**：抽象类、接口、虚方法与索引器
- **委托与事件**：delegate、event、Func 与 Action
- **集合**：常用数据结构与线程安全集合
- **迭代与 LINQ**：IEnumerable、迭代器与 LINQ 查询
- **反射与特性**：运行时类型检查与动态编程
- **异步与并发**：async/await、Task 与异步流（持续补充中）
- **数据与存储**：数据库访问与 ORM（持续补充中）

建议按照侧边栏从上到下的顺序学习，各主题相互独立，也可按需查阅。
