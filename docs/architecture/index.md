# 架构设计

本栏目收录软件架构与设计相关的知识，按主题组织：

- **设计模式**：GoF 设计模式的 C# 实现与解读（[已发布](./design-patterns/index)）
- **领域驱动设计（DDD）**：以领域为核心的建模与架构方法（[已发布](./ddd/index)）
- **测试驱动开发（TDD）**：测试先行驱动的开发实践（[已发布](./tdd/index)）
- **整洁架构（Clean Architecture）**：关注点分离的架构分层思想（规划中）

示例代码位于仓库 `src/DesignPatterns`、`src/DDD`、`src/TDD` 目录，可对照文档阅读。建议先掌握语言基础（Basic），再学习软件设计思想。
